# Programming Assignments (C)

C programming assignments from my BS Computer Science coursework at the University of Balochistan.

## Contents
- **Class Timing Assignment.c** — class schedule/timing exercise
- **Fibnocci to a certain number.c** — prints the Fibonacci series up to a given number
- **Fibonecci series nth.c** — finds the nth Fibonacci number
- **Income Tax on salary.c** — calculates income tax on a salary
- **Mass converter.c** (with `Mass converter pseudo code.txt`) — unit mass conversion, with its pseudocode
- **Matrix Calculator.c** — matrix operations calculator
- **Tic tac toe.c** — a two-player tic-tac-toe game
